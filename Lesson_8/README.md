# Инструкция по токену

Для запуска тестов необходим токен Yougile.
Как указать токен:

-**Windows (cmd.exe):**
set YOUGILE_TOKEN=ваш_токен

-**Windows (PowerShell)**
$env: YOUGILE_TOKEN="ваш_токен"

-**Linux/MacOs:**
export YOUGILE_TOKEN=ваш_токен

Переменную нужно задавать в том же терминале, из которого запускаются тесты. Если токен не передан, тесты не будут работать.
